# 자동 테스트

푸시하기 전에 게임이 깨지지 않았는지 한 번에 확인하는 테스트입니다. 게임 파일에는 영향이 없고, GitHub Pages 배포와도 상관없습니다.

- 설치된 **크롬(없으면 엣지)** 으로 게임을 실제로 열어서 눌러 봅니다.
- Supabase 요청은 **전부 가짜 응답**으로 받습니다 → 실제 서버 · 랭킹 · 계정에는 아무것도 안 보냅니다. 인터넷 없이도 돌아갑니다.

## 처음 한 번

[Node.js](https://nodejs.org) (LTS) 설치 후, 이 `tests` 폴더에서:

```
npm install
```

## 실행

```
npm test                 # 전부 (1~2분)
node run.js 카오스       # 이름에 "카오스"가 들어간 묶음만
HEADED=1 npm test        # 브라우저 창을 띄워서 보기 (PowerShell: $env:HEADED=1; npm test)
```

끝에 `✓ 통과 N개`가 나오면 성공, `✗`가 있으면 그 줄에 무엇이 기대와 달랐는지 나옵니다.
크롬 · 엣지를 못 찾으면 `CHROME_PATH` 환경 변수에 브라우저 실행 파일 경로를 넣어 주세요.

## 테스트 추가하기

`suites.js`에 `async '이름'(t, { browser, url }) { … }` 를 하나 더 넣으면 됩니다. 도구는 `lib.js`에 있습니다.

- `openGame(browser, url, { session, save, supabase })` — 로그인 상태 · 저장 데이터 · 가짜 서버 동작을 정해서 게임 열기. `calls`에 서버로 보낸 요청이 쌓임
- `toHub` · `launchRun(page, mode, chaos)` · `finishRun(page, score)` — HUB 들어가기 · 출격 · 판 바로 끝내기
- 게임 변수(`run`, `OPT`, `META`, `ens` …)는 전역이라 `page.evaluate(() => run.score)`처럼 바로 읽고 바꿀 수 있음
- `t.ok(조건, '설명')`, `t.eq(실제, 기대, '설명')`
