# 에테르 챔버 (Æther Chamber) — 미니게임

적이 쏜 탄환을 **패링으로 빼앗아 되돌려주는 것**이 유일한 공격인 2D 쿼터뷰 액션 게임.

## ▶ 플레이

*링크 윗쪽에 있으니 그쪽으로 가서 플래이 하십시오*\n
브라우저만 있으면 설치 없이 바로 플레이할 수 있습니다. 진행 상황은 브라우저에 자동 저장됩니다.

## 조작

| 키 | 동작 |
| --- | --- |
| WASD / 방향키 | 이동 |
| 마우스 | 바라보는 방향 (패링 시야) |
| E / 좌클릭 | 패링 |
| F | F 스킬 (회복 / 방어) |
| Q | Q 스킬 (벽 생성 / 위상 이동) |
| Enter | 벽 설치 준비 시간 건너뛰기 |
| ESC | 일시정지 |

키는 타이틀의 OPTIONS에서 바꿀 수 있습니다. HUB에서 `1`을 누르면 디버그 모드가 켜집니다.

## 게임 흐름

TITLE → HUB(강화 · 스킬 장착) → 전투(웨이브 10 → 보스 알레테이아 → 다음 사이클) → RESULT → HUB

## 기술

- 단일 HTML 파일 (HTML + CSS + JavaScript, Canvas 2D)
- 외부 라이브러리 · 이미지 · 사운드 파일 없음 (효과음은 WebAudio로 합성)
