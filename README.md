# 에테르 챔버 (Æther Chamber) — 미니게임

적이 쏜 탄환을 **패링으로 빼앗아 되돌려주는 것**이 유일한 공격인 2D 쿼터뷰 액션 게임.

## ▶ 플레이

**https://sinmustard.github.io/Aether_Chamber_Mine_Game/**

브라우저만 있으면 설치 없이 바로 플레이할 수 있습니다(PC · 폰). 진행 상황은 브라우저에 자동 저장되고, 로그인하면 서버에도 저장됩니다.

## 조작

| 키 | 동작 |
| --- | --- |
| WASD / 방향키 | 이동 |
| 마우스 | 바라보는 방향 (패링 시야) |
| E / 좌클릭 | 패링 |
| F | F 스킬 (회복 / 방어 / 대시) |
| Q | Q 스킬 (벽 생성 / 위상 이동 / 구속) |
| R | R 스킬 (덮어쓰기 / 복제 / 해킹 / 자동 패링) |
| Enter | 벽 설치 준비 시간 건너뛰기 |
| ESC | 일시정지 |

키는 타이틀의 설정에서 바꿀 수 있습니다. 폰은 화면 왼쪽 절반으로 이동, 오른쪽 절반으로 조준 · 패링합니다.

## 게임 흐름

TITLE → HUB(강화 · 스킬 장착 · 모드 선택) → 전투(웨이브 10 → 보스 알레테이아 → 다음 사이클) → RESULT → HUB

모드: 노멀 · 하드 · 데일리 · 카오스

## 파일 구조

| 경로 | 내용 |
| --- | --- |
| `index.html` | 화면 뼈대, 버전 캡션, css · js 불러오기 |
| `css/style.css` | 스타일 |
| `js/*.js` | 게임 코드 (구역별 18개 파일, `index.html`에 적힌 순서대로 실행) |
| `assets/enemies/` | 적 이미지. 이미지가 없는 등급은 벡터 도형으로 자동 대체 |

파일별 역할, 버전 올리는 방법은 [진행 요약 문서](에테르_챔버_진행_요약.md)의 2-1 · 2-2를 보세요.

## 기술

- HTML + CSS + JavaScript, Canvas 2D. 빌드 도구 · 외부 라이브러리 · 사운드 파일 없음 (효과음은 WebAudio로 합성)
- GitHub Pages로 배포 (main에 푸시하면 바로 반영)
- 로그인 · 클라우드 저장 · 랭킹은 Supabase
